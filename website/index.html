It never draws a cursor

This is the decision everything else follows from. The obvious way to build a cursor tool is a transparent always-on-top window that follows the mouse and paints a sprite. That approach is permanently laggy: the window is composited by the desktop compositor at your monitor's refresh interval, so it trails the real pointer by one to two frames â€” 8 to 33 ms â€” on any hardware, forever. It also breaks in fullscreen games and fights with anything else drawing on screen.

CursorForge does not do that. Every cursor it produces is a real .cur or .ani file registered with Windows, which means it is drawn by the graphics card's dedicated hardware cursor plane â€” the same path Windows uses for its own arrow. It updates at your mouse's polling rate with no compositing step at all. Zero added input latency is not a target here; it is a property of the design.

Free, and private by design

CursorForge is free. No paid tier, no trial, no licence key, no advertising, no account.

It does not collect, store or transmit any information about you, your computer or your hardware. There is no telemetry, no analytics, no crash reporting and no fingerprinting. Your settings, presets and imported cursors live in a folder on your own machine and never leave it. The only network request the app can make is checking GitHub for a new version, and that can be switched off.

The source is public under the MIT licence, so none of this has to be taken on trust.

What it changes

Only per-user pointer settings, under HKCU\Control Panel\Cursors â€” the same settings the Windows Settings app exposes. It needs no administrator rights, never writes machine-wide settings, installs no driver or service, and injects no code into any other process.

Before it changes anything, it snapshots your existing pointer scheme. Restore Windows Default replays that snapshot exactly, and the uninstaller runs the same routine automatically before removing anything.

Features

  • Catalog 216 full schemes across seven categories â€” precision, neon, minimal, retro, gaming, animated and fun. Each one defines all seventeen pointer roles, so you never end up with a neon arrow and a stock Windows hourglass.
  • Sharp Catalog cursors are vectors, rendered at 32, 48, 64, 96, 128, 160, 192 and 256 pixels into one multi-resolution file. Windows picks the right one, so they stay crisp at any scaling and at any accessibility cursor size.
  • Any colour Artwork ships as greyscale masters and is recoloured when you apply it, so 216 schemes times any colour you like costs the download nothing.

  • Blend Use your own image as the arrow and a catalog scheme for the other sixteen roles â€” the mode that turns one picture into a coherent pointer set.
  • It stays Theme changes, personalisation resets and Windows updates silently revert custom cursors. A lightweight watchdog notices and puts yours back.
  • Presets Save the whole pointer â€” scheme, colour, size, outline â€” and switch between saved presets from the tray or a global hotkey. Export and share them as a single file.

What it cannot do

Some applications draw their own pointer instead of asking Windows for one. Many games using raw mouse input, some remote-desktop sessions, and a few hardware-accelerated canvases fall into this category, and no cursor tool can change those without injecting code into them â€” which CursorForge will never do, because that is what trips anti-cheat systems and antivirus heuristics. This is an explicit non-goal, not an oversight.

Secure surfaces â€” the administrator prompt, Ctrl+Alt+Delete, the sign-in screen â€” always use the system cursors. That is Windows working correctly.

Cursor trails and click ripples would need exactly the always-on-top overlay this app refuses to use, so they are not offered.
