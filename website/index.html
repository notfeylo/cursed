About

What Cursed actually is

cursed — about

A cursor app that does the boring part for you

Windows has always let you change your pointer. It has never made it pleasant. The stock route is a Control Panel dialog from another decade, a file picker, and seventeen separate pointer roles you are expected to set one at a time — assuming you already have .cur files, which almost nobody does. Then a theme change or a feature update quietly puts the arrow back.

Cursed is the shortcut. It is a small, free Windows app that does two things properly: it turns any picture you already have into a genuine cursor file, and it applies a complete, consistent pointer set across every role Windows defines — then keeps it there.

What the app does

  • Any image becomes a cursor. Drop in a PNG, JPEG or GIF. The background is removed for you, the hotspot is worked out, and you get a real .cur or .ani rendered at eight sizes, so it stays sharp on any display. An animated GIF stays animated.
  • All seventeen roles, not just the arrow. The arrow, the hand, the text beam, the busy ring, every resize handle. No more custom pointer sitting next to a stock Windows hourglass the moment your PC copies a file.
  • 36 cursor packs, already installed. They ship inside the installer. Nothing is fetched, nothing is streamed, and the catalog works with the network unplugged.
  • It stays applied. Windows resets pointers on theme changes and updates. A watchdog notices and puts yours back, so the choice you made survives the machine disagreeing with it.
  • Bring cursors you already own. Existing .cur, .ani, .ico and TIFF files import directly, frames and all.
  • Size and shape are yours. Scale the whole set, or only the roles you name, without hunting for a larger copy of the artwork.

Why it is built this way

Cursed never draws a cursor. It tells Windows which cursor to draw, and Windows renders it on the graphics card's hardware cursor plane — the same path it uses for its own arrow. That is a deliberate constraint, not a shortcut: apps that paint a pointer sprite into an always-on-top window are composited by the desktop compositor and trail your real pointer by 8–33 ms, permanently. This one adds nothing.

What it does not do

  • No account, no sign-in, no licence key.
  • No telemetry, no analytics, no crash reporting.
  • No administrator rights, ever — the install is per-user.
  • No code injected into other programs, which is why a fullscreen game drawing its own crosshair from raw input keeps drawing it.

Your settings, presets and imported cursors live in a folder on your own machine and never leave it. Uninstalling puts all seventeen pointers back exactly as they were, and a script in the repository checks that before every release.

Requirements

Operating system
Windows 10 version 1803 or newer, or Windows 11. The floor is Microsoft's: the app window is Edge WebView2, and WebView2 support ended for Windows 7, 8 and 8.1.
Architecture
x64, ARM64 or 32-bit — a separate installer for each.
Runtime
Edge WebView2. Already present on Windows 11 and up-to-date Windows 10; fetched automatically if it is missing, or use the offline installer.
Disk space
About 40 MB installed, including all 36 cursor packs.
Permissions
None. Per-user install, no UAC prompt, and only your own registry hive is written.
Network
Not required. The only request the app can make is an update check, and that can be switched off.
