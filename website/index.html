About

What Cursed actually is

A small Windows app with one job, done properly: the pointer you want, everywhere Windows draws one.

The problem

Windows lets you change your cursor. It has never made it easy.

The stock route is a Control Panel dialog from another decade, a file picker, and seventeen separate pointer roles you are expected to set one at a time — assuming you already have .cur files, which almost nobody does. Then a theme change or a feature update quietly puts the arrow back.

Cursed collapses all of that into a window, a drop zone and a click.

What it does

  • Any picture becomes a cursor Drop a PNG, JPEG or GIF. The background comes off, the hotspot is found, and you get a real .cur or .ani at eight sizes. An animated GIF stays animated.
  • All seventeen roles The arrow, the hand, the text beam, the busy ring, every resize handle. No custom pointer sitting next to a stock Windows hourglass the moment your PC copies a file.
  • 36 packs, already installed They ship inside the installer. Nothing is fetched, nothing is streamed, and the whole catalog works with the network unplugged.
  • It stays applied Windows resets pointers on theme changes and updates. A watchdog notices and puts yours back, so your choice survives the machine disagreeing with it.
  • Cursors you already own Existing .cur, .ani, .ico and TIFF files import directly, frames and all.
  • Size is yours Scale the whole set, or only the roles you name, without hunting for a bigger copy of the artwork.

Why it is built this way

Cursed never draws a cursor. It tells Windows which cursor to draw, and Windows renders it on the graphics card's hardware cursor plane — the same path it uses for its own arrow. Apps that paint a pointer sprite into an always-on-top window get composited by the desktop compositor and trail your real pointer by 8–33 ms, permanently. This one adds nothing you can measure.

What it will not do

  • Ask for an account, a sign-in or a key
  • Send telemetry, analytics or crash reports
  • Ask for administrator rights, ever
  • Inject code into your games to force a crosshair

Your settings, presets and imported cursors sit in a folder on your own machine and never leave it. Uninstall and all seventeen pointers go back exactly as they were.
