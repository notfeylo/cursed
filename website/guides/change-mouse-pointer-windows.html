How to change your mouse pointer

Windows can change the size and color of its standard pointer. For a different shape, animation, or complete matching set, use cursor files or a cursor customization app.

Updated August 29, 2026

Use Windows Settings for size and color

  1. Open Start, then Settings.
  2. Select Accessibility, then Mouse pointer and touch.
  3. Choose a pointer style, color, and size that stays visible on your screen.

This is the quickest option when you like the Windows pointer shape and mainly want it to be easier to see. Microsoft documents these controls in its mouse settings guide.

Use Mouse Properties for individual cursor files

Search Windows for Mouse settings, open Additional mouse settings, and select the Pointers tab. From there, select a pointer role and browse to a .cur file for a still cursor or an .ani file for an animated cursor.

This gives you precise control, but a full scheme can require changing many roles one at a time. Save the result as a named scheme if you want to reuse it later.

Use Cursed for a complete set

  1. Open Cursed and choose one of the included cursor packs.
  2. Preview the design, then adjust its size or color if needed.
  3. Apply it to replace all 17 Windows pointer roles together.

Cursed can also turn your own picture or animation into a cursor. It changes per-user settings and does not require an administrator account.

Return to your previous pointer

If a custom cursor is hard to see or simply does not suit the desktop, restore the saved scheme from Cursed. You can also select a Windows scheme in Mouse Properties and apply it manually.
