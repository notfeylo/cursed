One-sentence description

Cursed is a free Windows cursor customization app that applies complete pointer schemes and turns pictures, GIFs, APNGs, and existing cursor files into real Windows cursors.

Product facts

  • Current release: Cursed 1.27.0 for Windows 10 and Windows 11.
  • Includes 83 cursor packs and changes all 17 Windows pointer roles together.
  • Creates native .cur and .ani files instead of drawing an overlay.
  • Imports pictures, GIF and APNG animations, and existing CUR, ANI, and ICO files.
  • Runs without an account, administrator access, ads, or telemetry in the desktop app.
  • Built with Tauri, Rust, React, and TypeScript; source code is available on GitHub.
