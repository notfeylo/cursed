## The uninstall gate

Run twice, in full: install → apply a cursor → 36 imported and 11 custom packs
present → uninstall (silent, which takes the default of removing everything) →
`scripts/verify-uninstall.ps1`.

**Second run: exit 0. Zero residue.**

- `%APPDATA%\Cursed`, `%LOCALAPPDATA%\Cursed`, `%LOCALAPPDATA%\dev.feylo.cursed`
  all gone — the last of these held 72 MB of WebView2 cache and was the folder
  previously left behind.
- Autostart `Run` value gone. 33 `Cursed — *` cursor schemes gone. No uninstall
  entry, no `HKCU\Software` keys, no shortcuts.
- All seventeen pointer roles byte-identical to their pre-install values, read
  unexpanded and compared against the snapshot the app itself captured on
  2026-08-09.

The **first** run reported fifteen failures, and they were the script's fault,
not the app's: `Get-ItemProperty` expands `REG_EXPAND_SZ`, so it compared
`C:\WINDOWS\cursors\aero_arrow.cur` against the stored
`%SystemRoot%\cursors\aero_arrow.cur` and called a byte-perfect restore broken.
Recorded here because a verifier that produces confident false failures is worse
than no verifier — it sends someone to "fix" correct code.

User data on this machine was backed up before both cycles and restored after;
500 files, 36 imported packs, 11 custom cursors and `original_scheme.json` all
verified present afterwards.

## Not verified

- **ARM64 and 32-bit installers on real hardware of those architectures.** Only
  the PE machine type was checked. The binaries are the right architecture and
  the code compiles and lints clean for each, but nothing has *run* on an ARM64
  or 32-bit Windows.
- **A machine with no WebView2 runtime.** Both the `downloadBootstrapper` path
  and the offline installer are unexercised against a machine that genuinely
  lacks the runtime. This is the main claim §5 of the brief wants tested and it
  needs a clean VM.
- **The Windows version guard's refusal path.** It passes on build 26200; it has
  never been seen to *stop* an install, because there is no Windows 8.1 here.
- **The uninstaller's "keep my presets" branch.** Only the removing default was
  run, because a silent uninstall cannot answer a dialog. The keep path is one
  `StrCmp` away and is not covered.
- **The full §9 clean-VM gate**: DPI scaling 100–200%, reboot persistence,
  autostart returning to the tray, offline behaviour, idle CPU and RAM. The
  Windows Sandbox route remains unavailable on Windows 11 Home; the VirtualBox
  route in §9 has not been set up.

## Judgement calls

**The offline installer is not the default.** Embedding the WebView2 runtime
takes the installer from 8.5 MB to 211 MB. It is published as a separate asset
instead, because the in-app updater downloads in the background unasked, and
making that 211 MB is a real cost on a metered connection for a runtime that is
already present on every Windows 11 and every updated Windows 10. Its filename
falls outside the pattern the updater accepts, so it can never be selected
automatically.

**Windows 7 and 8.1 are out of scope and always will be.** Microsoft ended
WebView2 support for them; the runtime will not install. The floor is Windows 10
1803 and the installer now says so rather than installing an app that starts,
shows no window and exits.
