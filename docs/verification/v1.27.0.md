## Measured, not assumed

**The catalog installs.** `a_clean_machine_installs_every_pack` points `APPDATA`
at a temporary directory and runs the real `install_missing()`: **83 packs in
1.02 s**, every one with both an arrow and a hand. A second call costs
**1.7 ms**, which is the assertion that matters — it proves no pack is being
re-imported on every launch, the failure this release was most likely to
introduce because all forty-seven downloads were named "... Cursor".

**Windows accepts every bundled cursor.** ~180 files through
`verify_loadable` — the same `LoadCursorFromFileW` the importer uses, so an
`.ani` is proved to animate rather than proved to yield one still frame.

**Every bundled photo-mode artifact matches its recorded checksum.** All 14 of
them, hashed against the constants in `photo.rs` at test time. This is the check
the download used to do on the user's machine, moved to the only place it can
still catch a wrong or truncated file: the machine building the release.

**The crop composition.** Four tests, including the one that makes the function
necessary — a rectangle drawn on a quarter-turned picture must be stored against
the original's *bottom* strip, not its left. On a square image, getting that
wrong looks plausible.

**Installer size.** 14.10 MB at 1.26.0, **22.60 MB** here, x64, measured off the
built NSIS output. The photo-mode payload is ~21 MB uncompressed and LZMA takes
most of it back.

**The bundler puts the runtime where the code looks for it.** `models_dir()`
resolves `<exe>/photo`, and the built tree has `target/release/photo/` holding
the model, the ONNX Runtime and the four C++ runtime DLLs under the base names
Windows matches imports by.

**No repository link is left in the app.** The frontend is clean of
`github.com`, and `every_external_link_is_allowed` scans every `openExternal`
call site in the frontend and asserts it against `ALLOWED_EXTERNAL`, which is
now a single entry and is not the repository.

## Not verified

- **Background removal running from an actual install.** The model produces a
  matte in the test run, which loads the runtime from the directory `build.rs`
  stages — the same files, resolved a different way. The release path resolves
  `<exe>/photo`, and that has been confirmed only as far as the files being
  there. Installing the built installer on a clean machine and cutting out one
  photograph is the check that closes it, and it has not been done.
- **The frontend audit at every window size and DPI.** §7 of the brief asks for
  every screen at min/default/max and 100–200% scaling. Dead controls were
  checked mechanically — there are none, and every external link is
  test-verified — but "nothing overlaps at 175%" cannot be established by
  reading the source, and was not established by looking.
- **Icon sizes.** In use: 10, 11, 12, 13, 14, 15, 16 px. They read as contextual
  rather than accidental — 13 inline, smaller inside tight chips — but that is a
  judgement made from the source, not from the screen, so they were left alone.
- **The two manual looks** added to the standing gate in v1.24.0 — a large
  accessibility pointer, and a photo cut-out against white. **Four releases old
  now and still never performed.**
- **An N to N+1 update on a clean VM**, and **ARM64 / 32-bit on real hardware of
  those architectures.** Unchanged, and still never run. This release makes the
  ARM64 and 32-bit case more interesting than usual: each installer now carries a
  different architecture's ONNX Runtime and C++ runtime, staged by `build.rs`,
  and only the x64 one has been built and looked at.

## Decisions recorded

- **The catalog stays at 83 third-party packs.** Replacing them with the 291
  generated packs was offered and declined. The generated catalog was confirmed
  to still compile and pass its own tests against today's API, so the option
  remains open; it was not taken.
- **The GPL-3.0 notice for Geared Brass and Geared Steel stays**, because those
  two packs stay. The Licences page says so, and their licence files are
  unpacked beside their cursors.
- **The copyright block is scoped to the application, the Cursed sigil and the
  pointer artwork drawn for it** — and says so in the block, so it cannot be
  read as a claim over the packs, the fonts or the libraries.
