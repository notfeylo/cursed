# Cursed backlink plan

The goal is relevant editorial links from pages that help Windows users, not a
large number of low-quality links. Never buy followed links, automate comments,
or trade links at scale.

## Assets worth linking to

- [Homepage](https://www.trycursed.com/) — product, current version, demo, and download.
- [Cursor guides](https://www.trycursed.com/guides) — practical Windows pointer answers.
- [CUR vs ANI reference](https://www.trycursed.com/guides/cursor-file-formats) — a technical reference for hotspots and display sizes.
- [Press kit](https://www.trycursed.com/press) — verified facts, screenshots, logo, and demo video.
- [Open-source repository](https://github.com/notfeylo/cursed) — code, releases, documentation, and build status.

## Priority outreach

1. Windows customization writers: offer the app and the CUR/ANI reference when
   they update cursor, accessibility, desktop setup, or Windows 11 articles.
2. Open-source Windows software lists: submit the GitHub repository with a short
   factual description and the supported Windows versions.
3. Accessibility writers: pitch the size, color, contrast, and restoration
   controls without claiming medical or accessibility certification.
4. Design and creator communities: share the image-to-cursor and GIF-to-cursor
   guides as practical resources, not as advertisements.
5. Reporters and newsletters covering small Windows utilities: provide the press
   page and offer direct answers or original screenshots.

## Short outreach note

Subject: A current Windows cursor resource for your article

Hi [name] — I noticed your page about [specific topic]. I maintain Cursed, an
open-source Windows app that applies complete cursor schemes and converts images
or animations into native CUR and ANI files. We published a concise reference on
[the relevant subject] here: [specific guide URL]. If it would make the article
more useful, you are welcome to cite it. Product facts and original screenshots
are at https://www.trycursed.com/press. No worries if it is not a fit.

## Tracking progress

Record the target URL, contact, exact resource offered, date, response, and live
link. Review links for relevance and referral traffic; do not judge the campaign
by raw link count alone.
